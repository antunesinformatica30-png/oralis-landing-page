# Oralis — Landing Page Odontológica

Landing page fictícia para uma clínica odontológica, desenvolvida como projeto de portfólio para demonstrar habilidades em desenvolvimento web e design de interfaces.

## Sobre o projeto

A Oralis foi concebida para apresentar tratamentos odontológicos, transmitir confiança e incentivar o visitante a conhecer os serviços da clínica.

O projeto combina uma identidade visual moderna, tons de azul-marinho e turquesa, fotografia integrada ao layout e animações sutis.

## Funcionalidades

- Hero com imagem integrada ao fundo.
- Apresentação de tratamentos odontológicos.
- Seções institucionais e de estrutura.
- Área de contato com mapa ilustrativo.
- Layout responsivo para desktop, tablet e dispositivos móveis.
- Animações de entrada durante a rolagem.
- Navegação por âncoras.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

## Objetivo

Demonstrar conhecimentos em estruturação HTML, estilização CSS, responsividade, interações com JavaScript e organização de um projeto web para portfólio.

## Aviso

A Oralis é uma marca fictícia criada exclusivamente para fins demonstrativos. Os dados de contato, endereço, mapa e informações profissionais são ilustrativos.
